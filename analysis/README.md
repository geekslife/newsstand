# 광역단체 본청 지방채 20년 분석

## 핵심 자료와 실행 순서

1. `collect_lofin_20y.py`
   - 행정안전부 지방재정365 공개 API에서 서울·경기·부산·대구·광주·대전·울산 본청의 2004~2024년 결산을 수집합니다.
   - 사용 API: 회계별 지방채 잔액(`ACCAM`), 재원별 회계별 세입결산(`FIACRV`), 성질별 단체별 세출결산(`SDSCF`).
   - 결과: `data/metro-head-office-2004-2024.csv`, `data/metro-head-office-2004-2024-raw.json`.

2. `metro_head_office_20y.py`
   - 2004년 말 잔액을 기초로 2005~2024년 증가율을 계산합니다.
   - 금융위기·코로나·지방세 증가율 하락·자본지출 비중·단체장 진영을 비교합니다.
   - 결과: `data/metro-head-office-20y-results.json`.

3. `build_metro_debt_workbook.mjs`
   - 원자료, 수식 기반 계산, 모형 결과, 출처와 검증을 하나의 감사용 엑셀 파일로 만듭니다.

분석 실행에는 NumPy가 포함된 Codex 번들 Python 환경을 사용했습니다. 수집 스크립트는 Python 표준 라이브러리만 사용합니다.

## 정의

- 본청 지방채: 일반회계·기타특별회계·공기업특별회계·기금회계의 지방채 잔액 합계.
- 순계 세입: 재원별 회계별 세입결산의 순계합계.
- 지방세: 재원별 회계별 세입결산의 지방세수입 순계.
- 자본지출: 성질별 단체별 세출결산의 4xxxx 항목 합계.
- 재정부담 지표: 본청 지방채 잔액 / 순계 세입 결산액. 공식 관리채무비율과 다릅니다.
- 금융위기 대응기: 기본 2009~2010년, 민감도 2008~2010년.
- 코로나 대응기: 2020~2021년.

## 이전 장기 민감도 파일

`metro_debt_20y.py`와 `data/metro-debt-2004-2024.csv`는 e-나라지표의 시도별 합계(시·군·구 포함)를 사용한 이전 민감도 분석입니다. 현재 기사와 핵심 결론에는 사용하지 않습니다. 본청 자료와 시도별 합계를 이어 붙이지 마십시오.
