# 광역 채무 20년 민감도 분석

`metro-debt-2004-2024.csv`는 e-나라지표의 행정안전부 「연도별 자치단체 채무현황」에서 옮긴 연말 채무 잔액입니다. 단위는 억원입니다.

- 원자료: https://www.index.go.kr/unity/potal/main/EachDtlPageDetail.do?idx_cd=1046
- 범위: 2004~2024년 말 서울·경기·부산·대구·광주·대전·울산
- 정의: 시도별 합계이며 시·군·구 채무를 포함합니다.
- 용도: 2005~2024년 20개 연간 변화율을 이용한 장기 민감도 분석

이 자료는 기사 본문의 2015~2024년 광역단체 본청 자료와 정의가 다릅니다. 따라서 두 시계열을 이어 붙이지 않고, 본청만 비교한 분석을 핵심 결과로 유지한 채 장기 방향을 확인하는 별도 검증에만 사용합니다.

분석은 당해 연도 연말 단체장에게 채무 변화를 귀속하는 방식과 전년도 연말 단체장에게 귀속하는 1년 시차 방식을 모두 계산합니다. 부산 2020년 권한대행 기간과 대전 2005년 임기 중 당적 변경은 해당 정당 비교에서 제외합니다.
